Game Launcher

Map each PC Games console to the Steam account that should receive its shortcuts. After adding a game to Steam, restart Steam for the shortcut to appear.

Accounts are discovered from <SteamPath>\userdata\ and labelled using each account's local display name.

Live status of the agent running on this client machine.

Windows Linux

Windows: move rom-agent.exe to a permanent folder (e.g. C:\rom-agent\), then right-click it and choose Run as administrator. It will install itself as a Windows service that starts automatically at boot.
