01 Hardware

Media and user data live on a Windows 10 machine at 192.168.0.110 with a SAS DAS attached via HBA. This box mounts it over CIFS at /mnt/server-pc.

PartitionUUIDFilesystemMount
nvme0n1p1A745-730Evfat FAT32/boot (ESP)
nvme0n1p2f2ba3164-49c0-4f90-bea6-8c7ada01d308btrfs/
nvme0n1p38034dca1-d1fd-41fd-bc45-941c2e1ef74cbtrfs/home

Swap: 4 GB swapfile at /swapfile.

CIFS mounts

Mount pointRemote pathPurpose
/mnt/server-pc//192.168.0.110/hsas01General DAS access (media, backups, music)
/var/lib/nextcloud/data//192.168.0.110/hsas01/Nextcloud/dataNextcloud user data; mounted with uid=991 so ownership checks pass
CIFS ownership note CIFS mounts don't support real UNIX ownership — ownership is set at mount time via uid=/gid= options. The Nextcloud data mount uid= is derived from homeserver.nextcloudUid (declared in modules/nextcloud.nix, default 991) — change it there and both the service user UID and the mount option update together.

03 Rebuilding

# Apply config changes
sudo nixos-rebuild switch --flake /etc/nixos#homeserver

# Test without making it the boot default
sudo nixos-rebuild test --flake /etc/nixos#homeserver

# Set as next boot without touching the running system
sudo nixos-rebuild boot --flake /etc/nixos#homeserver

# Roll back to previous generation
sudo nixos-rebuild switch --rollback

Flakes only see git-tracked files — stage changes before rebuilding:

git add <file>

06 Secrets

Never stored in this repo. Copy machine-to-machine (scp/USB) — never paste values into chat or logs.

/home/kryt/.smbcredentials chmod 600, owned kryt:kryt

Required for the CIFS mount.

username=<user>
password=<password>
domain=WORKGROUP
/var/lib/music-info/secrets.env chmod 600, owned music-info:music-info
DISCOGS_TOKEN=<your Discogs token>
EMBY_API_KEY=<your Emby API key>
EMBY_BASE_URL=http://localhost:8096
EMBY_EXTERNAL_URL=https://intrentaka.com

MUSIC_PATH is set in the systemd unit in modules/lan-apps.nix, not here.

/var/lib/pihole/secrets.env chmod 600, owned root:root
WEBPASSWORD=<your Pi-hole admin password>
/var/lib/nextcloud-admin-pass chmod 600, owned root:root

Single line: the Nextcloud admin password.

/var/lib/nextcloud/nc-secrets.php chmod 400, owned nextcloud:nextcloud

JSON format (despite the .php extension — nextcloud34 module requirement). Must preserve the original instanceid, passwordsalt, and secret values from the backup; changing them invalidates all user passwords.

{
  "instanceid": "<from backup config.php>",
  "passwordsalt": "<from backup config.php>",
  "secret": "<from backup config.php>",
  "mail_smtppassword": "<Gmail app password>"
}

07 Music library scanner

Reads metadata from the directory structure (Artist/Album/NN - Title.mp3) and MP3/FLAC duration headers using 16 parallel CIFS workers. Scans ~27,000 tracks in ~13 minutes. Full wipe + rebuild of the tracks table on every run.

Rescan after adding music to the DAS:

sudo systemctl start music-scanner
journalctl -fu music-scanner       # live progress

08 SSL / external access

Let's Encrypt via NixOS ACME (auto-renews). Port 80 and 443 must be forwarded from the router to this machine.

  • intrentaka.com / www.intrentaka.com → Emby (localhost:8096)
  • cloud.intrentaka.com → Nextcloud

09 Minecraft

sudo systemctl start minecraft-server-survival
sudo systemctl stop minecraft-server-survival

autoStart = false — does not start at boot. Also controllable from the homepage Minecraft card via the mc-control API (port 5020).

online-mode = false for LAN clients without Mojang accounts. Do not expose port 25565 externally without re-enabling online mode first.

NixOS gotcha mc-control uses /run/wrappers/bin/sudo (the setuid wrapper NixOS creates at boot), not /run/current-system/sw/bin/sudo, which lacks the setuid bit. If mc-control ever returns {"status":"unknown"} after a reinstall, verify /run/wrappers/bin/sudo exists and is setuid root.

10 Fresh install

  1. Partition 256GB SSD: 512MB EFI (vfat) + btrfs root + btrfs /home
  2. Mount at /mnt, /mnt/boot, /mnt/home
  3. nixos-generate-config --root /mnt — overwrites hosts/homeserver/hardware-configuration.nix
  4. Clone this repo to /mnt/etc/nixos/
  5. Create all secrets files listed above
  6. nixos-install --flake /mnt/etc/nixos#homeserver
  7. Reboot → passwd kryt → place .smbcredentials
  8. Verify CIFS mount: systemctl status 'mnt-server\x2dpc.mount'
  9. Run music scanner: sudo systemctl start music-scanner
  10. Restore Nextcloud and Pi-hole from DAS backups at /mnt/server-pc/Backups/
