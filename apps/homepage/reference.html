02 configuration.nix

Everything the machine fundamentally is. Not a service module — this file is not expected to grow into a list of optional features.

Identity & boot

Hostname homeserver, static loopback alias 192.168.0.120, systemd-boot, timezone Australia/Sydney, US keyboard, 4 GB swapfile.

Users

kryt UID 1000 and GID 1000 are pinned — changing them without a chown pass on the DAS share will break file ownership. sambashare GID 125 is also pinned; Emby (PGID=125), music-info, and Nextcloud all share it for DAS access.

Desktop

KDE Plasma 6 on X11 via SDDM. Pipewire audio, Bluetooth, printing (CUPS), polkit, colord, udisks2, upower.

Remote desktop (XRDP)

Uses a wrapper script as the session launcher: sets KWIN_COMPOSE=N to prevent kwin compositing crashes on the virtual XRDP display, and disables kscreenlocker autolock so an idle session never reaches an unresponsive lock screen.

Samba

smbd/nmbd enabled for printer-sharing parity. This machine has no data shares — the DAS at 192.168.0.110 is a client mount only. samba-wsdd enabled for Windows network discovery.

CIFS mounts

Mount pointRemoteNotes
/mnt/server-pc//192.168.0.110/hsas01General DAS — media, backups, music. gid=125
/var/lib/nextcloud/data//192.168.0.110/hsas01/Nextcloud/datauid= read from homeserver.nextcloudUid in modules/nextcloud.nix — change it there and the mount stays in sync

Base packages

vim, git, wget, curl, htop, ripgrep, claude-code, go, cifs-utils.

04 modules/

Each file is a self-contained service — firewall rules, systemd units, users, and state dirs all declared together. All modules are loaded unconditionally by flake.nix.

nginx.nix

Reverse proxy and static file server. Hosts the homepage on port 5000, terminates TLS for intrentaka.com (Emby) and cloud.intrentaka.com (Nextcloud) with Let's Encrypt via NixOS ACME. Ports 80 and 443 must be forwarded from the router.

nextcloud.nix

Nextcloud 34 from nixpkgs-unstable (via overlay). MySQL backend, Redis cache, SMTP via Gmail. Declares homeserver.nextcloudUid (default 991) — this is the single source of truth for both the service user UID and the CIFS mount uid= in configuration.nix. Nextcloud services depend on the data CIFS mount before starting.

emby.nix

Emby media server in a Podman container (pinned digest). PUID=0, PGID=125. Media at /mnt/server-pc. Config at /var/lib/emby/. Exposed externally via nginx.

audiobookshelf.nix

Audiobookshelf in a Podman container (pinned digest). Port 13378. Media at /mnt/server-pc/Media. Library path /media/Audio Books.

pihole-container.nix

Pi-hole DNS ad-blocker in a Podman container. Admin UI at port 8083. Internal port pinned to 8080 via FTLCONF_webserver_port — Teleporter restores would otherwise flip it back to 80. LAN DNS at port 53. Split-horizon entries at /var/lib/pihole/etc-pihole/custom.list (not tracked in the repo — recreate after a full volume wipe).

lan-apps.nix

All custom LAN apps declared here. Sources are canonical copies in apps/.

music-info secrets at /var/lib/music-info/secrets.env. Music scanner: sudo systemctl start music-scanner — reads Artist/Album/NN - Title.mp3 with 16 parallel CIFS workers, ~27,000 tracks in ~13 minutes.

minecraft.nix

NeoForge 1.20.1 server via nix-minecraft. autoStart = false — never starts at boot; use mc-control or systemctl start minecraft-server-survival. online-mode = false for LAN. World and mods at /var/lib/minecraft/survival/ — persistent state, never touched by a rebuild.

NixOS gotcha mc-control uses /run/wrappers/bin/sudo (the setuid wrapper), not /run/current-system/sw/bin/sudo which lacks the setuid bit. If mc-control returns {"status":"unknown"} after a reinstall, verify /run/wrappers/bin/sudo is setuid root.

mumble.nix

Murmur voice server registered as "hometalk". Port 64738 TCP+UDP. Data at /var/lib/murmur. Connect to 192.168.0.120:64738. SuperUser password is printed once to the journal on first start.

databases.nix

MySQL for Nextcloud.

mjh-proxy.nix

Internal proxy service. Source at apps/mjh-proxy/.

05 Rebuilding

Flakes only see git-tracked files — always git add before rebuilding.

# Stage, commit, and apply
sudo git -C /etc/nixos add <file>
sudo git -C /etc/nixos commit -m "message"
sudo nixos-rebuild switch --flake /etc/nixos#homeserver

# Test without making it the boot default
sudo nixos-rebuild test --flake /etc/nixos#homeserver

# Roll back to previous generation
sudo nixos-rebuild switch --rollback

Tag stable states:

git tag working-YYYY-MM-DD
systemctl --failed              # anything that didn't start
journalctl -u <service> -f     # live logs

07 Fresh install

  1. Partition 256 GB SSD: 512 MB EFI (vfat) + btrfs root + btrfs /home
  2. Mount at /mnt, /mnt/boot, /mnt/home
  3. Clone this repo to /mnt/etc/nixos/
  4. nixos-generate-config --root /mnt — overwrites hardware-configuration.nix at repo root
  5. Create all secrets files listed above
  6. nixos-install --flake /mnt/etc/nixos#homeserver
  7. Reboot → passwd kryt → place .smbcredentials
  8. Verify CIFS: systemctl status 'mnt-server\x2dpc.mount'
  9. Run music scanner: sudo systemctl start music-scanner
  10. Restore Nextcloud and Pi-hole from DAS backups at /mnt/server-pc/Backups/
