# modules/nixos-unstable/nextcloud.nix

Configures Nextcloud using `pkgs.nextcloud34` (from the unstable overlay). Nextcloud data is stored on the DAS CIFS mount; the database is MariaDB managed by `databases.nix`.

## Package source

`nextcloud34` is pulled from `nixpkgs-unstable` via the overlay in `flake.nix`. The stable channel does not have this version.

## Core settings

| Setting | Value |
|---|---|
| `hostName` | `cloud.intrentaka.com` |
| `database` | MySQL, `createLocally = true` (MariaDB auto-setup) |
| `configureRedis` | true (Redis session cache) |
| `secretFile` | `/var/lib/nextcloud/nc-secrets.php` |
| `adminuser` | `admin` |
| `adminpassFile` | `/var/lib/nextcloud-admin-pass` |

## secretFile

`/var/lib/nextcloud/nc-secrets.php` is a JSON file despite the `.php` extension (required by the NixOS nextcloud34 module). It must preserve the original `instanceid`, `passwordsalt`, and `secret` values from backup — changing any of these invalidates all existing user passwords.

## CIFS dependency

`nextcloud-setup.service` has `after` + `requires` on `var-lib-nextcloud-data.mount` (the CIFS mount defined in `configuration.nix`) to ensure the DAS is reachable before Nextcloud initialises.

## Nginx

The Nextcloud nginx vhost is auto-generated by the NixOS nextcloud module but is overridden here with:

```nginx
return 503;
```

This is a temporary block for CVE-2026-109618/109619 (PHP RCE). The `= /status.php` location returns 404 additionally. Remove `extraConfig` once nixpkgs ships a patched PHP build.

## PHP hardening

`disable_functions` blocks: `system`, `passthru`, `pcntl_exec`, `exec`, `proc_open` — prevents PHP-level code execution in the event of an application compromise.

`phpfpm-nextcloud.service` also has `after`/`requires` on the CIFS mount and receives `config.homeserver.sandbox`.

## Preview generation

A `nextcloud-preview-gen` oneshot service runs every 15 minutes via a systemd timer. It finds all image, video, and PDF files under the Nextcloud data directory and calls `nextcloud-occ preview:generate` for each. The timer uses `Persistent = true` so missed runs are caught on next boot.

## UID

`users.users.nextcloud.uid` is pinned to `config.homeserver.uids.unstable.nextcloud` (991). This UID must also match the `uid=` mount option on the CIFS data mount in `configuration.nix`. They cannot diverge.
